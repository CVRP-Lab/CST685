## Synthetic House Price Dataset (CST 685)

This file contains a **synthetic (artificially generated)** dataset used in **CST 685** to practice **linear regression** and basic data handling workflows (loading data, plotting, training, evaluation).

### Columns
- **House_Size_sqft**: House size in square feet (numeric)
- **House_Price_$**: House price in U.S. dollars (numeric)

### Example Rows
| House_Size_sqft | House_Price_$ |
|---:|---:|
| 1360 | 283642.46 |
| 1794 | 376554.97 |
| 2138 | 423456.68 |
| 2669 | 521330.45 |
| 3419 | 665835.84 |

### Notes
- This dataset is **not real housing market data** and should not be used for real-world pricing decisions.
- Values are designed to roughly follow a linear relationship (larger houses tend to cost more), with some variation to simulate noise.

### Intended Use in CST 685
Students will use this dataset to:
- Load tabular data (CSV/TSV)
- Visualize relationships (scatter plot)
- Train a **linear regression** model
- Compute evaluation metrics (e.g., **MSE**, **MAE**, **R²**)
